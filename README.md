# ShizukuVirtualCam v2.3 (100% Offline 6D / 6DoF Virtual Camera)

## Features
- **Zero Internet / Zero Cloud API**: Runs completely offline on your Android device (no `INTERNET` permission required).
- **True 6D (6DoF) Depth-Relief Engine**:
  - Builds an anatomical 3D facial depth model (skull ellipsoid, nose bridge protrusion, cheeks, eye sockets) from your face photo.
  - Controls all 6 spatial axes in real time: **Yaw, Pitch, Roll, X-Shift, Y-Shift, and 3D Perspective Depth Z**.
  - Adds subtle 3D Lambertian micro-shading as the face rotates so lighting responds naturally to movement.
- **Offline Gyro 6D Sensor Mode**: Gently tilt/move your phone to drive live 6D head movement over Brave hands-free.
- **6D Auto-Move**: Smooth critically-damped spring physics with organic human pauses, breathing depth Z, eye-gaze saccades, and asymmetric blinks.
